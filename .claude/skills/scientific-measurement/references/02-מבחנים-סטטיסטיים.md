## 1. רווח סמך — כמה אנחנו באמת יודעים

מספר בודד מטעה. "78 אחוז" נשמע מדויק, אבל במדגם של 349 מילים
הטווח האמיתי הוא 73.3 עד 82.0.

```python
import math

def wilson(correct, total, z=1.96):
    """רווח סמך של 95 אחוז לשיעור הצלחה.

    נבחרה שיטת וילסון ולא הנוסחה הפשוטה, כי הפשוטה נשברת בקצוות:
    ב-0 מתוך 20 היא נותנת רווח של אפס רוחב, כלומר "אנחנו בטוחים
    לגמרי שזה אפס" — וזה שקר.
    """
    if not total:
        return 0.0, 0.0, 0.0
    p = correct / total
    d = 1 + z * z / total
    centre = (p + z * z / (2 * total)) / d
    half = z * math.sqrt(p * (1 - p) / total + z * z / (4 * total * total)) / d
    return p * 100, max(0.0, centre - half) * 100, min(1.0, centre + half) * 100
```

**תמיד לדווח את הרווח.** "272 מתוך 349 = 77.9% (73.3 עד 82.0)".

## 2. מבחן מובהקות — האם ההפרש אמיתי

```python
def significant(c1, n1, c2, n2, z=1.96):
    """האם ההפרש בין שתי מדידות חורג מהרעש.

    מחזיר: (האם מובהק, ההפרש בנקודות אחוז, גבול הרעש)
    """
    if not n1 or not n2:
        return False, 0.0, 0.0
    p1, p2 = c1 / n1, c2 / n2
    se = math.sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)
    noise = z * se * 100
    diff = (p2 - p1) * 100
    return abs(diff) > noise, diff, noise
```

### כוח המבחן — החולשה שחייבים להכיר

```python
def min_detectable(total, p=0.5, z=1.96):
    """ההפרש הקטן ביותר שאפשר לזהות במדגם בגודל נתון."""
    return z * math.sqrt(2 * p * (1 - p) / total) * 100
```

## 3. השוואה מזווגת — המבחן החזק

**ההבחנה:** המבחן למעלה מניח שתי מדידות **עצמאיות**. אבל כשמשווים
את אותה מערכת על אותם פריטים, ההשוואה **מזווגת** — וזה הרבה יותר
חזק.

```python
def paired_compare(before_clips, after_clips):
    """משווה פריט מול פריט.

    before_clips, after_clips: מילון שם -> תוצאה
    """
    worse  = [(n, before_clips[n], after_clips[n]) for n in before_clips
              if n in after_clips and after_clips[n] < before_clips[n]]
    better = [(n, before_clips[n], after_clips[n]) for n in before_clips
              if n in after_clips and after_clips[n] > before_clips[n]]
    same = len(before_clips) - len(worse) - len(better)
    return {"worse": worse, "better": better, "same": same}
```

### שני מצבים, שתי רמות חומרה

**שינוי בסביבה** — החלפת ספרייה, מעבר לחומרה אחרת, עדכון גרסה:

> הפלט אמור להיות **זהה**. כל שינוי הוא סימן.
> גם שיפור לא צפוי — הוא אומר שהחישוב השתנה, וצריך להבין למה.

**שינוי בהגדרות או במודל:**

> שינוי בפלט צפוי. כאן בודקים אם הסכום השתפר, ומסתכלים על
> הפריטים שהורעו כדי להבין את המחיר.

## 5. יישור מילה למילה

ספירת מילים משותפות אינה מספיקה: היא סופרת מילה שהופיעה במקום
הלא נכון כנכונה.

```python
def count_correct(ref, hyp):
    """כמה מילים נכונות, לפי יישור.

    בונה מטריצת מרחק עריכה, ואז עובר אחורה כדי לספור התאמות
    מדויקות בלבד.
    """
    n, m = len(ref), len(hyp)
    d = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        d[i][0] = i
    for j in range(m + 1):
        d[0][j] = j
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            cost = 0 if ref[i - 1] == hyp[j - 1] else 1
            d[i][j] = min(d[i-1][j] + 1, d[i][j-1] + 1, d[i-1][j-1] + cost)

    i, j, correct = n, m, 0
    while i > 0 and j > 0:
        if ref[i-1] == hyp[j-1] and d[i][j] == d[i-1][j-1]:
            correct += 1
            i -= 1; j -= 1
        elif d[i][j] == d[i-1][j-1] + 1:
            i -= 1; j -= 1
        elif d[i][j] == d[i-1][j] + 1:
            i -= 1
        else:
            j -= 1
    return correct
```

**ולהבדיל בין סוגי שגיאה.** מילה שהוחלפה, מילה שנשמטה ומילה
שנוספה הן שלוש תקלות שונות עם שלוש סיבות שונות. מספר אחד מאחד
אותן ומסתיר את הסיבה.
