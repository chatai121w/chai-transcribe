## ההבחנה המרכזית

> **עומס משפיע על המהירות, לא על הדיוק.**
>
> מנוע עמוס עונה את **אותה תשובה בדיוק**, רק לאט יותר.

מכאן נובע הכלל המעשי:

| מדד | מושפע מעומס | ניתן להשוואה תחת עומס |
|---|---|---|
| דיוק, ספירת מילים, נכונות | **לא** | **כן** |
| זמן, יחס לזמן אמת, תפוקה | **כן** | **לא** |

מדידה תחת עומס מסומנת כ**לא ניתנת להשוואה במהירות**, והדיוק שלה
נשאר תקף במלואו.

## מה למדוד

| מה | למה דווקא זה |
|---|---|
| מעבד — ממוצע, שיא, **וכמה מהזמן היה עמוס** | ממוצע לבדו מסתיר עומס קצר וחזק. עומס של שתי דקות מתוך עשר נעלם בממוצע, והוא בדיוק זה שהאט |
| זיכרון פנוי — **מינימום**, לא ממוצע | מחסור רגעי גורם לגלישה לדיסק, וזה איטי בסדר גודל |
| ניצול הכרטיס | ניצול נמוך פירושו שהצוואר אינו בכרטיס |
| זיכרון הכרטיס — **שיא** | קרוב לגבול, ווינדוס גולשת לזיכרון המערכת בלי שום הודעה |
| חום ותדר | כרטיס נייד מאט תחת עומס מתמשך |
| **סיבות האטה** | הסיבה המדויקת, מהיצרן |
| תוכנות כבדות שרצות במקביל | זה מה שמסביר את הפער |

## קודי ההאטה של הכרטיס

```python
THROTTLE_REASONS = {
    0x0001: "הכרטיס בטל",
    0x0002: "הגדרת תדר של התוכנה",
    0x0004: "הגבלת חשמל בתוכנה",
    0x0008: "האטה בחומרה",
    0x0010: "סנכרון בין כרטיסים",
    0x0020: "האטה בגלל חום, בתוכנה",
    0x0040: "האטה בגלל חום, בחומרה",
    0x0080: "בלם חשמל בחומרה",
    0x0100: "הגדרת תדר של המסך",
}
```

הקוד הוא מסכת סיביות — כמה סיבות יכולות להיות פעילות יחד.
**קוד שאינו ברשימה אינו שגיאה**: היצרן מוסיף סיבות בגרסאות
חדשות. לדווח אותו כ"סיבה שאינה מוכרת" ולא להתעלם.

```python
def decode_throttle(raw):
    if not raw or raw in ("Not Active", "N/A", ""):
        return []
    value = int(str(raw), 16) if str(raw).startswith("0x") else int(raw)
    out = [name for bit, name in THROTTLE_REASONS.items() if value & bit]
    unknown = value & ~sum(THROTTLE_REASONS)
    if unknown:
        out.append(f"סיבה שאינה מוכרת ({hex(unknown)})")
    return out
```

## איך דוגמים

```python
class Monitor:
    """דוגם ברקע תוך כדי העבודה.

    ממוצע אחרי הכל מסתיר את התמונה. נשמרות גם הפסגות וגם כמה
    מהזמן המחשב היה עמוס.
    """
    def __enter__(self):
        self.before = snapshot()
        self._thread = threading.Thread(target=self._loop, daemon=True)
        self._thread.start()
        return self

    def __exit__(self, *a):
        self._stop.set()
        self._thread.join(timeout=4)
        self.after = snapshot(with_neighbours=False)
```

## הסיווג

```python
def verdict(summary):
    problems = []
    if summary["cpu"]["avg"] > 55:
        problems.append(f"המעבד היה עמוס {summary['cpu']['avg']}% בממוצע")
    if summary["cpu_busy_pct_of_time"] > 25:
        problems.append(f"המעבד היה מעל 60% במשך "
                        f"{summary['cpu_busy_pct_of_time']}% מהזמן")
    if summary["free_gb"]["min"] < 2.0:
        problems.append(f"הזיכרון הפנוי ירד ל-{summary['free_gb']['min']} ג׳יגה")
    if summary["gpu_mem"]["max"] > 7000:
        problems.append(f"זיכרון הכרטיס הגיע ל-{summary['gpu_mem']['max']:.0f} מגה")
    if summary["throttle"]:
        problems.append("הכרטיס הואט: " + ", ".join(summary["throttle"]))

    if not problems:
        return "נקי", []
    heavy = [p for p in problems if "עמוס" in p or "ירד" in p or "הגיע" in p]
    return ("תחת עומס" if heavy else "עם הסתייגות"), problems
```

שלוש דרגות:

| דרגה | מה זה אומר |
|---|---|
| **נקי** | המדידה ניתנת להשוואה במלואה |
| **עם הסתייגות** | משהו לא אידיאלי, אבל לא מספיק כדי לפסול |
| **תחת עומס** | מספרי המהירות חסרי ערך. הדיוק תקף |

## מדידה נקייה — איך משיגים

כשבאמת צריך מספר מהירות אמין:

1. לסגור את שרת ההפעלה והדפדפן.
2. לסגור מכונות וירטואליות.
3. להריץ חימום.
4. לוודא שהסיווג יצא **נקי** לפני שמאמינים למספר.

ואם זה לא אפשרי — **לומר שהמספר משוער**, ולהישען על הדיוק
שאינו מושפע.
