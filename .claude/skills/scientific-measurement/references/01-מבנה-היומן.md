### למה כל שדה קיים

| שדה | בלעדיו |
|-----|--------|
| `git.commit` | יודעים שהיה טוב יותר, לא יודעים ממה |
| `git.dirty` | מדידה שנלקחה עם שינויים לא שמורים אינה ניתנת לשחזור, וחושבים שכן |
| `words` | משווים מדגמים שונים ומסיקים שטות |
| `machine_verdict` | מספר המהירות חסר משמעות |
| `versions` | עדכון ספרייה שבר משהו, ולא יודעים מתי |

### הכלל הקריטי

**משווים רק מדידות עם אותו מספר פריטים.**

מדידה על 340 מילים ומדידה על 100 אינן ניתנות להשוואה: אפשר לקבל
אחוז גבוה יותר פשוט בגלל פריטים קלים יותר. מדידה חלקית נרשמת
ביומן אבל **אינה נכנסת לחישוב השיא**.

```python
def comparable(rows, words):
    return [r for r in rows
            if r.get("words") == words and r.get("correct") is not None]

def best_ever(rows, words):
    pool = comparable(rows, words)
    return max(pool, key=lambda r: r["correct"]) if pool else None
```

### ארבעת השדות

| שדה | על מה הוא עונה |
|-----|-----------------|
| **השערה** | מה ציפינו שיקרה, ולמה חשבנו כך |
| **שינוי** | מה בדיוק שונה |
| **תוצאה** | מה קרה בפועל |

**הלקח שווה יותר מהמספר**, כי הוא מונע את הניסיון הבא.

### כלל הכתיבה

הלקח חייב לענות על **"מה לא לנסות שוב, ולמה"**. לקח שכתוב
"זה לא עבד" אינו שווה כלום. לקח שכתוב "קרבה פונטית אינה מספיקה
כי המילון שונה" מונע משפחה שלמה של ניסיונות.

### ההשערה נרשמת לפני

אחרי שרואים את התוצאה, קל לשכנע את עצמך שזה בדיוק מה שציפית.
השערה שנרשמה בדיעבד תמיד "מתאימה", ולכן אינה מלמדת כלום.

## השומר

מחפש ביומן הלקחים ניסיונות דומים, ועוצר אם משהו כבר נפסל.

```python
def _keywords(text):
    words = re.findall(r"[א-תa-zA-Z0-9][א-תa-zA-Z0-9\-]{2,}",
                       str(text or "").lower())
    return {w for w in words if w not in STOPWORDS}


def find_similar_attempts(description, threshold=0.22):
    want = _keywords(description)
    hits = []
    for r in read_lessons():
        text = " ".join(str(r.get(k) or "") for k in
                        ("label", "hypothesis", "change", "outcome", "lesson"))
        have = _keywords(text)
        shared = want & have
        # יחס מול הקצר מביניהם: תיאור קצר מול לקח ארוך עדיין אמור
        # להתאים. יחס מול האיחוד היה מחמיץ את זה.
        score = len(shared) / min(len(want), len(have))
        if score >= threshold:
            hits.append((score, sorted(shared), r))
    return sorted(hits, key=lambda x: -x[0])
```

**נבדק בפועל** ותפס ניסוח שונה לגמרי של אותו רעיון: "הקראה
סינתטית" נתפס מול הלקח שנרשם על "קול מלאכותי".

### השומר אינו חוסם בכוח

הוא עוצר ומראה למה. אם בכל זאת ממשיכים — צריך לומר **מה שונה
הפעם**. אחרת זה אותו ניסיון עם אותה תוצאה.

## רשימת החבילות

```
benchmark_private/regression/freeze/<שם-המדידה>.txt
```

רשימה מלאה, שורה לכל חבילה.

**למה זה קריטי:** התקנת חבילה אחת משדרגת תלויות **בשקט**. בניסוי
אמיתי התקנה של מנוע גרפים שדרגה את numpy מ-2.4.4 ל-2.5, מה ששבר
את numba, ששבר את librosa, ששבר את שכפול הקול — שלוש שכבות משם.

**החזרה לא הייתה שלמה:** הוחזר מה שהותקן ביודעין, לא מה שהשתנה
כנזק צדדי. בלי הרשימה המלאה אי אפשר לדעת מה זז.

```bash
# לפני
pip freeze > before.txt

# אחרי — מה באמת השתנה
diff <(sort before.txt) <(sort after.txt)

# לשחזר
pip install -r before.txt
```
