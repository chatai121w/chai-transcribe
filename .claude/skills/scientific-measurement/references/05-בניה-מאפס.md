### שלושה כללים

מדגמים בגדלים שונים.

## שלב 3 — השוואה מול השיא

**זה הלב של הכל.**

```python
def best_ever(rows, size):
    pool = [r for r in rows if r.get("words") == size
            and r.get("correct") is not None]
    return max(pool, key=lambda r: r["correct"]) if pool else None
```

**לא מול הקודם. מול השיא.** אחרת: 280 → 240 → 265 נראה כשיפור,
ובפועל הוא ירידה של 15.

## שלב 4 — קישור לגיט

```python
def git_state():
    commit = git("rev-parse", "--short=12", "HEAD")
    status = git("status", "--porcelain") or ""
    dirty = [l[3:] for l in status.split("\n") if l.strip()]
    # קבצי תוצאות ומסמכים אינם הופכים מדידה ללא ניתנת לשחזור
    relevant = [f for f in dirty
                if not f.startswith(("benchmark/", "docs/"))
                and not f.endswith((".log", ".md"))]
    return {"commit": commit,
            "branch": git("rev-parse", "--abbrev-ref", "HEAD"),
            "subject": git("log", "-1", "--format=%s"),
            "dirty": bool(relevant),
            "dirty_count": len(relevant)}
```

**מה זה נותן:**

```bash
git diff <נקודת-השיא>..HEAD --stat        # מה השתנה מאז
git switch -c חזרה-<נקודה> <נקודת-השיא>   # לחזור, לענף נפרד
```

**החזרה היא לענף נפרד ולא דריסה.** מה שיש עכשיו נשמר.

**לשמור בגיט לפני המדידה.** מדידה שנלקחה עם שינויים לא שמורים
אינה ניתנת לשחזור, ויש לסמן אותה ככזאת.

## רשימת בדיקה למי שבונה את זה

- [ ] המדגם קפוא ומאושר, והגודל נרשם בכל מדידה
- [ ] ההשוואה מול השיא ההיסטורי, לא מול הקודם
- [ ] מדגמים בגדלים שונים **אינם** מושווים
- [ ] כל מדידה קשורה לנקודת שמירה בגיט
- [ ] מדידה עם שינויים לא שמורים מסומנת כלא ניתנת לשחזור
- [ ] רשימת החבילות נשמרת בכל מדידה
- [ ] ההשוואה מדווחת על חבילות שהשתנו, גם בלי שביקשנו
- [ ] מצב המחשב מנוטר לאורך כל המדידה
- [ ] מדידה תחת עומס מסומנת, ומהירותה אינה מושווית
- [ ] הדיוק מושווה תמיד, גם תחת עומס
- [ ] השוואה מזווגת פריט מול פריט, לא רק סכומים
- [ ] פריט שאיבד יותר ממחצית מסומן כבעיה
- [ ] רווח סמך מדווח תמיד
- [ ] הכלי אומר מפורשות כשההפרש בתוך הרעש
- [ ] יומן לקחים עם ארבעת השדות
- [ ] השומר רץ לפני ניסיון
- [ ] **הכלי עצמו נבדק** — שהוא באמת רושם ובאמת תופס רגרסיה

**השורה האחרונה אינה פורמלית.** בפרויקט הזה התגלה שהיומן לא קיבל
מדידה, והכלי הכריז "אין מדידה קודמת" — ביטחון שווא. אחרי כל שינוי
בכלי, לבדוק שהוא עובד על מקרה מלאכותי שאתה יודע את תשובתו.
