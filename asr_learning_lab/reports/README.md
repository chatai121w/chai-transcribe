# Reports

Commit only small, intentional experiment summaries. Generated transcripts, checkpoints, caches, and bulk reports belong in the ignored `../artifacts/` directory.

Every final report must identify the base model, dataset fingerprint, Gold source, config, Train/Test WER and CER before and after, checkpoint-save result, checkpoint-reload result, isolation result, regression-gate result, and an explicit `VERIFIED` or `NOT VERIFIED` conclusion.
