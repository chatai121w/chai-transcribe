# מתי תיקון הופך לכלל ומתי ללימוד קולי

תאריך: 2 בספטמבר 2026

## התשובה

כן. הדוגמה `ילדים → ילדות` מדגימה היטב מדוע אסור להפוך כל תיקון אנושי
לכלל החלפה גלובלי.

שתי המילים תקינות. העובדה שבמופע מסוים המנוע כתב `ילדים` והדובר אמר
`ילדות` אינה מוכיחה שכל פעם שהמנוע כותב `ילדים` צריך להחליף ל-`ילדות`.

כלל כזה לומד:

```text
כאשר מופיע הטקסט "ילדים", כתוב "ילדות"
```

אבל מה שאנחנו רוצים ללמד הוא:

```text
כאשר האודיו במופע הזה מבטא "ילדות", כתוב "ילדות"
```

הראשון הוא כלל טקסט מסוכן. השני הוא דוגמת אימון אקוסטית.

## מה צריך לקרות בעת תיקון כזה

כאשר מתקנים `ילדים` ל-`ילדות`:

1. מתקנים את המופע הנוכחי בלבד בתמלול.
2. שומרים את קטע האודיו המדויק ואת הטקסט `ילדות` כ-Gold, לאחר אימות.
3. לא יוצרים אוטומטית כלל גלובלי `ילדים → ילדות`.
4. אפשר לשמור את הצמד כ-Candidate עם ההקשר, אך לא להפעילו על כל טקסט.
5. לאחר צבירת דוגמאות מגוונות, מאמנים LoRA או adapter כדי ללמוד את הצליל.

## מתי כן מותר כלל טקסט

כלל גלובלי מתאים בעיקר כאשר צד המקור אינו מילה לגיטימית, או כאשר התיקון
כמעט אינו תלוי בהקשר.

לדוגמה:

```text
ביסודז → ביסודות
```

אם `ביסודז` אינה צורה תקינה בשום הקשר רלוונטי, ההחלפה בטוחה יחסית.

לעומת זאת, ההחלפות הבאות מסוכנות ככללים גלובליים:

```text
ילדים → ילדות
הוא → היא
אמר → אומר
רבי → רב
```

שני הצדדים תקינים, והבחירה תלויה באודיו או במשפט.

## שלוש רמות תיקון

### 1. תיקון למופע בלבד

המשתמש מתקן את המילה בתמלול הנוכחי. אין השפעה על מקומות אחרים.

מתאים תמיד.

### 2. תיקון תלוי הקשר

המערכת שומרת גם את המילים מסביב, הדובר, המנוע וקטע האודיו. היא יכולה להציע
את התיקון בעתיד כאשר ההקשר דומה, אך אינה מחילה אותו אוטומטית בכל מקום.

לדוגמה:

```text
"הבנות והילדים" אינו אותו הקשר כמו "קבוצת הילדות"
```

### 3. לימוד קולי

שומרים:

```text
audio span + "ילדות"
```

ומאמנים מודל על הרבה מופעים. כך המודל לומד להבחין בין הצליל של `ילדים`
לצליל של `ילדות`, תוך שימוש גם בהקשר השפתי.

## האם דוגמה אחת מספיקה?

דוגמה אחת מספיקה כדי לתקן את המופע ולבדוק את הצינור. היא אינה מספיקה כדי
ללמד בבטחה את המודל שכל צליל דומה הוא `ילדות`.

צריך דוגמאות שונות:

- אותו דובר במשפטים שונים.
- דוברים שונים.
- מהירות והטעמה שונות.
- גם דוגמאות חיוביות של `ילדות`.
- גם דוגמאות נגדיות של `ילדים`.

דוגמאות נגדיות חשובות מאוד. אם מאמנים רק על `ילדות`, המודל עלול להתחיל
להעדיף אותה גם כאשר באמת נאמר `ילדים`.

## מדיניות אוטומטית מומלצת

בעת תיקון אנושי המערכת צריכה לסווג:

| סוג התיקון | פעולה אוטומטית |
|---|---|
| שגיאה שאינה מילה תקינה | מועמד לכלל גלובלי, לאחר אישור |
| שתי מילים תקינות | תיקון למופע + Gold אקוסטי |
| ביטוי קבוע וחד-משמעי | מועמד לכלל תלוי הקשר |
| שינוי פיסוק או ניסוח | עריכת טקסט בלבד, לא אימון ASR |
| אדם אימת קטע מול אודיו | Gold לאימון |

## המסקנה

`ילדים → ילדות` אינו כלל. זו **ראיית אימון** שאומרת שבקטע האודיו המסוים
נאמר `ילדות`.

המטרה היא לא ללמד את המערכת ש-`ילדים` פירושו `ילדות`. המטרה היא ללמד אותה
להקשיב טוב יותר ולהחליט לפי הצליל וההקשר מתי נאמרה כל אחת מהמילים.
